A tiny Node 22 program that writes one original one-sentence pitch to the output file the make.fun judge reads. The pitch speaks to a friend who has never coded: describe an app idea in plain words, get a working first version to try on make.fun — no code, no cost, and the only thing at stake is the sentence itself.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
